
                                                                D-FLEX
                                                                
                                            Decentralized Fleet Management for Autonomous Mobile Robots

Project Overview : 

D-FLEX is a decentralized warehouse automation system designed to improve the coordination and movement of multiple Autonomous Mobile Robots (AMRs). It focuses on intelligent path planning, dynamic route management, and efficient multi-robot coordination.

The system allows robots to navigate warehouse environments, detect obstacles, identify route conflicts, and dynamically adjust their paths based on changing conditions.

                                                     Problem Statement

Traditional warehouse automation systems often depend on centralized control, which can create communication bottlenecks, traffic congestion, and coordination challenges when multiple robots operate simultaneously.

D-FLEX aims to address these challenges through decentralized coordination and intelligent path-planning techniques.

                                                      Key Features

- Decentralized coordination between multiple robots.
- A* algorithm for efficient pathfinding.
- Dynamic route replanning when obstacles are detected.
- Conflict detection to identify overlapping robot paths.
- Spatio-temporal reservations for managing shared spaces.
- Deadlock detection and recovery mechanisms.
- Route updates for improved robot coordination.

                                                      System Workflow

1. Robots receive navigation tasks within the warehouse.
2. The A* algorithm calculates an efficient path.
3. Robot movements and possible route conflicts are monitored.
4. When an obstacle or blockage occurs, an alternative route is generated.
5. Robots exchange route updates to coordinate their movements.
6. Conflict resolution and deadlock recovery mechanisms help maintain smooth operations.
